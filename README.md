# 노동환 | Dong-Hwan Noh

**Data Analytics · Applied Statistics**

사회환경공학과 응용통계학을 바탕으로 공급망 위험 분석, 보험 모형 평가, 통계 방법론 연구 및 학술연구 상담을 수행했습니다. 분석 목적에 맞는 지표 설계, 결과 검증, 의사결정을 위한 해석과 전달에 중점을 두고 있습니다.

- **학력:** 건국대학교 사회환경공학부·응용통계학 복수전공 / 응용통계학 석사과정
- **주요 경험:** 통계상담실장, 공급망·산불보험 프로젝트 팀장, 통계 방법론 논문 2편 제1저자
- **관심 분야:** 비즈니스·고객 데이터 분석, 데이터 기반 제품·전략 의사결정
- **분석 도구:** R · Python · SPSS · AMOS · Excel
