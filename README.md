# 노동환 · Dong-Hwan Noh

Applied Statistics / Data Analysis

건국대학교에서 사회환경공학과 응용통계학을 복수전공하고, 응용통계학 석사과정에서 통계 방법론을 연구하고 있습니다. 공급망 위험과 보험, 환율 데이터를 분석했고, 통계상담에서는 연구자의 질문을 분석 계획으로 정리해 재분석과 결과 보고까지 맡았습니다.

분석을 시작할 때는 무엇을 비교하고 어떤 판단에 쓸지 먼저 확인합니다. 결과가 나오면 비교군, 학습에 쓰지 않은 자료, 독립 계산으로 해석이 유지되는지 점검합니다.

## 사용 도구

R로 위험지표, 시계열 모형, 교차적합과 모의실험을 구현했습니다. 설문 연구에서는 SPSS와 AMOS로 신뢰도와 경로모형을 분석했고, Python과 Excel을 자료 확인과 정리에 사용했습니다.

각 저장소에는 담당 범위, 결과의 해석 한계와 실행 조건을 적었습니다. 논문 투고본은 Notion 상세 페이지에서 확인할 수 있습니다.
